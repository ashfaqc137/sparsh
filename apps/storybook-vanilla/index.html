sparsh — vanilla storybook

A dedicated, correctly-labeled repro per canonical case (see prompts/00-context/problem.md). Each section has its own deterministic "Arm" trigger. Toggle global/per-policy mode below, then try each case in both report and enforce mode.

Controls

Global mode:

⚠️ Apply recreates the guard, which starts a brand-new age tracker with no memory of elements inserted before this moment. Click Apply before arming a case, not while a transient element (toast/banner) from a previous arm is already on screen — otherwise that element's age is untracked (ageMs = Infinity) and AgePolicy will allow it unconditionally, regardless of cooldownMs or mode.

1a · Interstitial — occlusion

A toast mounts exactly over an existing button (no reflow). The whole press lands on the toast's own control because it freshly covers the target.

Caught by: AgePolicy (the clicked element is young).

fired: 0

1b · Interstitial — mid-press identity swap

Press-and-hold on the button below; mid-press a toast mounts and covers it, so pointerup resolves to the toast's control instead (different identity, same coordinates, no reflow).

Caught by: ContinuityPolicy (identity differs between down and up).

fired: 0

2 · Layout shift

Content loads above the target via normal document flow and displaces it downward — a different pixel now holds the button by the time pointerup fires.

Caught by: ContinuityPolicy (rect moved past threshold).



fired: 0

3 · Late render

The slot below is empty. A real control materializes into it; a press that begins after the control exists (both down and up) lands squarely on it.

Caught by: AgePolicy only (identity/rect match — Continuity sees nothing).

fired: 0

4 · Async settle

Same element, same pixels — only meaning changes. Uses aria-disabled (a truly disabled element dispatches no pointer events at all).

Caught by: SemanticsPolicy (disabled field diff) when the press spans the enable (down while disabled, up after enabled); AgePolicy (re-armed perceivable-age on the enable transition) when the entire press — down and up — happens after it's already enabled, within cooldownMs.

fired: 0

5 · List reorder

Shuffle swaps the underlying entities while keeping the same DOM nodes/positions (simulating a recycled/virtualized list). Row A carries data-guard-key; row B does not.

Caught by: SemanticsPolicy via opt-in guardKey — row A blocked, row B is a documented gap (allowed).
